プライバシーポリシー

施行日：2026年11月27日

Dahliaは、macOS向けの会議文字起こし・ノートアプリです。本ポリシーでは、Dahliaがアクセスするデータ、 利用・保存方法、Macの外部へ送信する場合、およびデータを管理・削除する方法を説明します。

原則としてローカル保存。

会議内容とGoogleユーザーデータは、Mac、およびユーザーが選択したバックアップ、書き出し先、保存場所、外部アカウントにおいて ユーザーの管理下に置かれます。外部送信は、それを必要とする機能を有効にするか実行した場合に限ります。後述する診断情報は、 これとは別に送信される場合があります。

1. Dahliaが取り扱うデータ

会議データ

Dahliaは、音声、文字起こし、要約、ノート、スクリーンショット、プロジェクト、タグ、アプリ設定を保存できます。 これらはMacと、ユーザーが設定したバックアップに保存されます。

GoogleアカウントおよびCalendarデータ

Googleのプロバイダーアカウントを追加すると、アカウントID・表示名・メールアドレスとCalendar・Driveの読み取り権限を まとめて求めます。利用する機能は個別に選択します。Calendarを有効にすると、カレンダー一覧と選択した カレンダーの今後の予定にアクセスします。予定には、タイトル、説明、開始・終了時刻、参加状態、予定種別、 カレンダー・予定識別子、会議リンク、Google Calendarリンクが含まれる場合があります。アクセスは読み取り専用で、 Dahliaが予定を作成、編集、削除することはありません。

Google Driveデータ

Google Driveの権限（drive.file）で、DahliaはDahliaが作成したフォルダとファイルだけにアクセスでき、 Drive内のほかのファイルは見えません。バックアップの保存先にGoogleアカウントを選ぶと、Dahliaは 「マイドライブ/Dahlia/backup」を作成し、作成したバックアップをアップロードして、一覧・ダウンロード・削除を行います。 Dahliaでバックアップを削除すると、Driveのゴミ箱に移します。バックアップには、選択したWorkspaceの会議・文字起こし・ 要約・スクリーンショットが含まれます。Dahlia AIによるGoogle Docsへの書き出しは、別途設定したMCP接続とその権限を使用し、 AI接続の承認設定に従います。

診断情報

Dahliaはクラッシュレポート、匿名化された技術エラー区分、および処理区分、音源区分、locale、診断code、少数の 言語処理件数、Piインストール失敗の固定段階・理由・HTTPステータスなど許可リスト内の短い技術情報をSentryへ送る場合があります。 PiのダウンロードURL、インストール先、応答本文、生のエラー文は送信しません。ネットワークとlifecycle breadcrumbの 自動捕捉および既定の個人情報送信を無効にし、request、user、extraフィールドを除去しています。 検索索引や画像解析の失敗には固定の処理区分とエラー区分だけを使用し、モデル名、providerの応答、SQL、生のエラー詳細は送りません。 アプリが応答しなくなった場合は、固定の画面区分、停止時間の範囲、録音中かどうかを送ります。2秒以上の停止では、 アプリのスレッドのスタックトレースも含めます。会議名、内容、正確な停止時間は送りません。

匿名の利用状況分析

Dahliaは、録音、文字起こし、要約生成、書き出しが開始・完了・失敗したか、AIチャットを利用したか、内蔵AIがDahliaの MCP toolを利用したかという低頻度のworkflow eventをTelemetryDeckへ送信します。eventには文字起こし方式、録音開始時に 有効な音源、新規または再開録音、Quick Recordingまたはカレンダー自動録音という固定の実行契機、書き出し先、失敗段階、 内蔵AIの処理元、read/write、粗い機能分類の固定区分が 含まれる場合があります。完了した録音については、録音時間を分単位に四捨五入して最大360分に制限した数値も送信します。 外部clientによるMCP利用、MCP tool名、引数、結果は送信しません。TelemetryDeck SDKは、インストールごとのハッシュ化ID、 匿名session ID、アプリ・SDK version、 OS・端末特性、言語、locale、地域、timezone、外観、accessibility設定、時刻・曜日などのcalendar bucket、初回利用日、 session数、利用日数、直前・平均session時間も付加します。Dahliaは診断・利用eventへ、 会議内容、チャットのプロンプト・応答、氏名、メールアドレス、ファイルpath、ローカルレコードID、認証情報、自由文のエラーメッセージを添付しません。

2. データの利用目的

Dahliaは、ユーザーが選択した次の機能を提供するためにデータを利用します。

  • 会議の録音、文字起こし、整理、検索、表示
  • 選択したカレンダーの今後の予定表示と、予定からの会議準備
  • 予定と会議の関連付け、およびユーザーが実行した要約・AIチャットへの予定情報の利用
  • 作成したバックアップのGoogle Driveへのアップロード、および一覧・ダウンロード・削除と復元。AI経由のGoogle Docsへの書き出しは別途設定したMCP接続を使用します。

また、上記の匿名利用状況と匿名化した技術診断を、機能の信頼性測定、障害調査、品質改善のために利用します。

Googleユーザーデータを販売せず、広告や信用判断に利用せず、汎用AIモデルの学習・改善にも利用しません。

3. 保存場所と保持期間

  • OAuthアクセストークン、更新トークン、GoogleアカウントID、表示名、メールアドレスはOAuthセッションとしてmacOS Keychainに保存し、そのプロバイダーアカウントをサインアウトまたは削除するまで保持します。
  • 今後のGoogle Calendar予定は、メモリとアプリのアカウント・プロバイダー別のローカルスナップショットに保持します。そのカレンダーの接続解除でスナップショットを削除します。
  • 予定を保存済み会議に関連付けると、タイトル、説明、日時、識別子、リンクを使用中のローカル会議DBと、ユーザーが作成した DBバックアップに保存します。使用中のDBでは、その予定を参照する会議がある間だけ保持し、最後の参照会議を削除した後に 削除します。既存のバックアップ内のコピーは、そのバックアップを削除するまで残ります。
  • 選択したプロバイダーとカレンダーのIDはローカル設定に保存します。ダウンロードしたバックアップからMac上に データを復元します。復元した会議と保持したローカルバックアップは、ユーザーが削除するまで残ります。
  • 書き出したGoogle Docsは、ユーザーがGoogle Drive上で削除するまで残ります。
  • TelemetryDeck SDKはbest-effort送信のため有界のローカルqueueを保持します。UserDefaultsには直近90日分の session詳細を保持し、初回利用日、累計session数、累計利用日数はアプリデータが削除されるまで保持します。 匿名の利用状況と診断情報は、TelemetryDeckおよびSentryの各サービスポリシーに従って保持されます。

Dahliaの開発者は、Google Calendarの予定、Google Drive文書、会議録音、文字起こしを受信・保存するサーバーを運営しません。

4. AIサービスとその他の外部送信

要約を生成する場合、バッチ文字起こし後の自動要約を有効にした場合、またはAIチャットを使用する場合、その要求に必要な内容を 設定済みのAI接続先へ送信します。会議が予定に関連付けられている場合、予定のタイトル、説明、開始・終了時刻が含まれることが あります。接続先はユーザーのアカウントと、その事業者の規約・プライバシーポリシーに従って処理します。Googleアカウントを 接続したり、予定を表示しただけでCalendarデータをAIサービスへ送ることはありません。

バックアップとDriveへの要求は、MacからGoogleへ直接送信します。Dahlia AIへGoogle Docsへの書き出しを依頼した場合、 設定済みMCP接続がその権限で要求した内容をGoogleへ送信します。その他の場合は、 本ポリシーに記載したユーザー向け機能の提供を除き、セキュリティ上必要な場合または適用法令に従う場合に限って Googleユーザーデータを開示します。

5. Googleデータの管理と削除

  1. 今後のアクセスを停止：CalendarまたはDriveを無効化・接続解除すると、その機能による利用が停止します。 プロバイダー設定でGoogleアカウントをサインアウトまたは削除すると、その登録のローカル認証情報を削除し、Calendarと Driveの両方を停止します。他のGoogle登録、Databricks接続、別途設定したMCP接続は切断されません。Google側の認可を 取り消すには、Googleアカウントの「サードパーティとの接続」ページからDahliaを削除してください。
  2. 保存済み予定の詳細を削除：その予定に関連付けた会議を削除します。参照する会議がなくなると、使用中のDBから 保存済み予定を削除します。バックアップ内のコピーを削除するには、DahliaのDBバックアップも別途削除してください。 Dahliaのローカルアプリデータを削除しても、別の場所へ書き出したバックアップは削除されません。
  3. Driveファイルとバックアップを削除：Dahliaでバックアップを削除するとDriveのゴミ箱に移します。 Google Drive上で削除することもできます。サインアウトではGoogle Drive上のファイルやバックアップは削除されません。 取り込んだ会議とローカルバックアップは別途削除してください。
  4. Google側のアクセスを確認：Googleアカウントの「サードパーティとの接続」ページからもDahliaのアクセスを 取り消せます。

6. セキュリティ

Dahliaは、PKCEを用いたGoogle OAuth、Google・AIサービスとのHTTPS通信、OAuth認証情報用のmacOS Keychain、コード署名、 macOSのアクセス制御を使用します。Mac、ローカルバックアップ、Googleアカウント、設定済みAIアカウントの保護は ユーザーの責任となります。

7. Google API Services User Data Policy

DahliaによるGoogle APIから受け取った情報の利用および転送は、Limited Use要件を含む Google API Services User Data Policy に準拠します。

8. 変更とお問い合わせ

Dahliaのデータ取扱いに重要な変更がある場合、本ポリシーを更新します。機密情報を含まない一般的な質問または技術的な報告は、 公開のDahliaのIssue Trackerからお問い合わせください。Dahliaの メンテナーは会議内容またはGoogleユーザーデータを受信・保存しておらず、Mac、バックアップ、外部アカウントのデータへアクセス したり削除したりできません。上記の手順に従ってユーザー自身で管理・削除してください。公開Issueには、会議内容、認証情報、 その他の機密情報を記載しないでください。
