02 · Dahliaとは

会議を録る・残す・活かすを、
ひとつの流れに。

Dahliaは、ひとりで使うmacOSの会議記録アプリです。会議中のメモを減らし、あとから確かな情報へ戻れる状態をつくります。

1

録る

マイクとシステム音声を録音し、画面の変化とカレンダー予定も会議にまとめます。

2

残す

音声と画像を一次ソースとして保持し、会議後に精度を優先してバッチ文字起こしします。

3

活かす

Summaryを読み、必要なら根拠をたどり、ObsidianやGoogle Docsへ書き出します。

03 · 会議中

会議中は、音声と画面を並行して保存。

Dahliaは録音音声と自動取得した画像を、同じMeeting・同じ時間軸の一次ソースとして残します。

会議の前

会議中

2つの一次ソース

自分と相手の会話を保存

撮影時刻とともに保存
会議の後

ポイント： リアルタイム文字起こしではなく、録音後のバッチ処理を基本にしています。

07 · 検索 · 準備中

同じ言葉も、近い意味も探せるように。

全文検索とベクトル検索を組み合わせ、言葉が一致する記録と、内容が近い記録の両方を見つけるハイブリッドサーチを準備しています。

SEARCH

「あの会議で決めた共有方法」

会議名や発言を正確に思い出せなくても、覚えている言葉から検索します。

FTS5 全文検索

同じ言葉

名前や用語など、入力した言葉が含まれる記録を素早く探します。

Gemma Embedding

近い意味

言い換えや似た内容をベクトルで比較し、意味が近い記録を探します。

HYBRID SEARCH

2つの結果をまとめて、見つけやすい順に。

言葉の一致と意味の近さを組み合わせ、目的のMeetingへ案内します。

言葉が一致した記録内容が近い記録

準備中の機能です。 検索対象や結果の並べ方など、仕様・表示は変更になる場合があります。

09 · AIから参照

まずSummary。必要なときだけ、元の記録へ。

アプリ内AIとMCPは、同じ保存済みMeetingを参照します。短い答えから始め、詳細が必要な場合だけ根拠をたどります。

Dahliaアプリ内AIアプリの中で、その会議や過去の記録に質問先週から何が変わった？
MCP選んだVault内を、既定で読み取り専用に参照Claude Code / Codex
選択したVault内の保存済み記録READ ONLY by default
STEP 1Summaryを読む

まず少ない情報で、要点と答えをつくる

STEP 2 · 必要時根拠を確認

確定した文字起こしやスクリーンショットを参照

録音音声や未確定の処理結果は、MCPの参照対象に含みません。
