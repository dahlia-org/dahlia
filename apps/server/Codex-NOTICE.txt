Dahlia's databricks-models.json contains selected runtime metadata derived from
the Codex catalog, with Dahlia display names and without OpenAI-internal
transport and lifecycle fields. Generation expands Databricks public IDs and
adds non-OpenAI models. GPT reasoning levels and defaults follow the referenced
Codex release. The fallback prompt is derived from models-manager/prompt.md.
