# アプリが開いている間の定期エージェント

採択: 2026-11-15。利用者が定期実行を製品範囲として見直し、実装を指示した。

[always-on エージェント](always-on-agent.md)には、外部への書き込み・取り込み・インボックスへの配信を認める。
この仕様の定期実行そのものは、always-on の Timer に寄せるまで以下の制約に従う。

汎用の統合基盤・業務ワークフロー自動化は引き続き作らない。一方、利用者が確認した予定で、
既存の会議ツールと登録済み外部 MCP を読み取って個人の判断材料を届ける機能を macOS 内蔵 Pi に認める。
録音中、アプリ終了中は開始しない。常駐サービス、起動時 daemon、クラウドの時計は作らない。
閉じていた間や睡眠中の未実行は予定ごとに1回にまとめる。

create/resume/有効な予定のupdateは Auto review で pi-auto-review が審査し、許可できない操作・審査失敗はユーザーに確認、critical は拒否する。
Supervised と fullAccess はユーザーに確認する。審査・確認した prompt・schedule・skills・読み取りツール名の組に revision を振り、保存時に同じ改訂であることを検証する。
後から追加したツールは使えない。readOnlyHint は提供側の申告であり、情報の持ち出しを防ぐ保証ではない。
予定の権限は実行開始後に緩められず、bash、ファイル書き込み、memory、skill_manage、スレッド操作、再帰的な予定作成は禁止する。
thread と schedule を合わせて3本まで、対話は待たせず、ふり返りは別に1本とする。

予定ごとに閲覧専用の結果 Thread を持ち、発火ごとに --no-session の新しい Pi を起動する。
前回の静音でない結果は8000字まで引き継ぐ。静音・失敗は Hermes の印で判定し、結果と未読を SQLite に保存する。
停止・削除・変更は古い待機分だけを捨て、実行中の処理は通常の停止操作で止める。
着手済みの発火は再起動で interrupted とし、勝手にやり直さない。

macOS の通知は予定ごとに切れる。返信や業務データの変更、別の配信先、常駐実行は今回の範囲外。
