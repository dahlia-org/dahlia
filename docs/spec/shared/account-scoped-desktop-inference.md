# アカウント別の Desktop 推論と操作元による実行場所

採択: 2026-10-02。ユーザー承認済み。

この仕様は、[処理場所](transcription-summary-processing.md)の Desktop 側の扱いと、[アカウント](../desktop/accounts.md)ごとのモデル設定スコープ、生成用 runtime の切替を定める。

## 決定

Desktopの文字起こし・再文字起こしはApple Speech、要約・画像解析は内蔵 Pi（[内蔵 Pi runtime](../desktop/pi-runtime.md)）で行う。
Desktop のアカウントはアプリの 1 つだけで、モデルは ChatGPT・Claude のサブスクリプションと、プロバイダーアカウント（Databricks の接続、Dahlia account）の Gateway から選ぶ。
Desktop の Workspace はどのアカウントにも属さず、データの所属をモデルプロバイダーから推定しない。

生成用の内蔵 Pi は 1 つの agent directory で動き、Workspace 切替では停止しない。
録音・文字起こし・保存済み結果は Pi の停止から独立させる。
プロバイダーや接続が変更済みなら、古い要約要求は失敗として再実行を促す。
選択した設定の適用中は完了まで待ち、適用に失敗した場合は待機を解除してエラーにする。
認証管理用の既存サービスは生成に使わない。

このMacのUserDefaultsへアプリのアカウントのキー（`local`）で、チャット・要約のモデルと推論強度、画像解析のモデル、
画像検索の有効化、要約スタイル、録音後の自動処理、live draftを保存する。
画像解析のモデルは検索用 OCR・caption と要約前の画像選別で共用する。推論強度は設定にせず、用途ごとの値は [内蔵 Pi runtime](../desktop/pi-runtime.md) に従う（保存されていた値は使わない）。画像検索を無効にしても選択と選別は維持する。Webの画像検索スイッチはDesktopの初回設定への引き継ぎ用とし、既存のMacアカウントの画像検索はそのMacで設定する。Web要約前の画像選別はこのスイッチによらず実行する。

DesktopとWebで共有するWorkspaceの既定値は出力言語のみとする。サーバー用のモデル・推論強度・音声処理方法・要約スタイルは、Webから明示的に生成する場合のWorkspace既定値として保持する。実行時に上書きでき、Desktopのアカウント設定には適用しない。Desktopで生成した結果を同期で受け取ってもサーバーで自動生成しない。モデル一覧から選択モデルが消えても保存値は変更せず、その要求だけ既定へ戻す。

Desktop要約は文字起こしを入力ソースとする（既存のノート・画像補助は維持）。音声からの直接要約は提供せず、
再文字起こしと要約を別操作にする。手元の音声が削除済みなら既存の認可・checksum検証付きアーカイブ取得経路でM4Aを取得する。
全文の成功前に既存文字起こしを置き換えない。

Webから明示的に開始した文字起こし・要約は既存Serverキューを使う。同期や不足データの巡回だけではServer画像解析を登録しない。
Webの画像解析操作は今回追加しない。検索・Memory・Gatewayの推論リレーは引き続きServerが担当する。

## 互換性とデータ保護

v0.24.xのprocessingJSONはremote・audio・cloudTranscription・serverRequestを含めて読み取る。旧remote処理は再開せず、
Macで再実行できる失敗として表示する。不正JSONは該当録音だけをスキップして通知し、他の録音の復元を続ける。
旧DB列と登録済みmigrationは変更しない。

Server設定の既知の旧キーは受け付け、旧クライアントが読める応答形状を維持する。未知のキーは拒否する。
旧キーを新しい実行場所判定に使わない。旧imageAnalysis要求も同期の互換入力として受け付け、AI生成は登録しない。
Desktopは同期しないので、要約はローカルに保存するだけとする（[同期契約](sync.md#正本とアカウント境界)）。

## T5への適用

Desktop音声処理をMacに統一する。クラウド音声処理の例外は、Webから利用者が明示的に開始した保存済み録音の処理に限定する。
ServerアカウントのGateway利用は音声処理のServer委譲を意味しない。

## 却下した案

- 生成用 runtime として Codex app-server を使う: 元の記録に理由の記載はない。現在は内蔵 Pi を使う。
