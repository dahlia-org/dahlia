# 会話分析（ベータ）

会話分析は、録音音声と確定済み文字起こしから、話す速度、発話バランス、会話の密度、同時発話を表示します。
設定の「詳細」→「ベータ機能」で有効にできます。

## 利用条件

次の条件をすべて満たす場合だけ、ミーティング詳細に会話分析タブを表示します。

- Server Account の owner Vault
- Server が `conversationAnalytics: { version: 1 }` を通知している
- 対象ミーティングの録音音声が Server に保存・確定されている
- 表示中の文字起こし版が Server と同期済みである

レビューは読み取り専用で、要約やMeetingを書き換えません。マイク音声を本人、システム音声を
相手側として扱いますが、システム音声は複数人を含み得るため、個人への話者特定は行いません。

Local Account、共有された member Vault、古い Server では利用できません。文字起こしの同期前は同期後に利用できる旨を、
対応する確定音声が不足している場合はその理由をタブ内に表示します。

## 所有と版

計算は Server だけが行い、Desktop は表示中の `transcriptId` と `transcriptVersion` を明示して結果を取得します。
応答の ID と版が一致しない場合や、取得中に表示版が変わった場合は結果を破棄します。版は immutable なので、結果を保存する
専用テーブルや非同期ジョブは持たず、タブを開いたときに同期計算します。

`transcript_segments.normalized_character_count` には、原文から空白を除いた Unicode 書記素数を保存します。新規作成と本文更新では
Server が計算し、版コピーでは値もコピーします。既存行の `NULL` は未計算を表し、その版の初回分析時に本文を復号して補完します。
補完後の分析は本文を読まず、時刻、音源、文字数だけを使います。別の metrics version 列は持ちません。

## 音源と指標

- `mic` を「自分」、`system` を「相手側」と表示します。
- 選択版の生成metadataが参照する録音だけを録音番号順に連結し、絶対時刻から各セグメントを対応する録音へ割り当てます。
- Desktop生成では `recordingSessionId`、Server生成では録音番号・音源・checksumを照合します。参照metadataがない旧版や照合できない音声がある版は分析できません。
- 音源を判定できないセグメントは集計しません。
- 終了時刻がない、逆転している、または補正後の長さが 0 のセグメントは文字数と件数に含め、時間指標から除外します。

| 指標 | 定義 |
| --- | --- |
| 発話速度 | `normalizedCharacterCount / sourceSpeechDuration × 60` |
| 発話比率 | `sourceSpeechDuration / Σ sourceSpeechDuration` |
| 会話占有率 | `unionSpeechDuration / recordingDuration` |
| オーバーラップ率 | `overlapDuration / unionSpeechDuration` |
| 最長連続発話 | 同一音源の区間を3秒以内の間隔で結合した最長区間 |

通常の発話区間は同一音源内の重なりと1.5秒以内の間隔を結合します。発話ペースは最小1分単位で、長時間会議では
音源ごとに最大60点へ集約します。会話の流れは指標の正確な区間を保持したまま、表示用だけ最大512区間へ集約します。
分母が0の場合は0%ではなく算出不可です。

## 対象外

プロソディ、盛り上がり、声の抑揚・同調、エネルギー推移は初版に含めません。将来の音響分析は、録音checksum集合、モデル、
schema versionをキーにした独立テーブルへ保存し、文字起こし版から分離して再利用します。Gemini用の空テーブル、依存、設定は
先行追加しません。Desktopの旧分析テーブルと音響列はユーザーデータ保全のため削除せず、未使用のまま残します。
